# Constitution

The owner's standing rules. Every agent reads this file at the start of every run.

**This file is not a wall.** A PRD that runs into a rule is not wrong for running into it: the validator raises it as a question for the owner, and the owner answers. A rule the owner overrules is rewritten, not carved out.

**No agent adds a rule here.** Only the owner does, and only after the product has shown it needs one. Rules are added when something has actually gone wrong, not in advance against what might.
