# Proposed changes to the loop

Lessons that hold for any project, not just this one, written by a person: the retro fixes the loop here, in `project.md` or a Machinery change the check-in applies, and never files to this page. The owner takes them to the loop's repository as a pull request. Each entry: the date, the loop file it changes, the proposed rule, and the evidence (feature, finding, metric).
